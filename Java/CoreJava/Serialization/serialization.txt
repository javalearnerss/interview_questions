------------------------------------------------------------------------------------

Serialization (Java) — The process of converting an object into a byte stream so it can be stored or transmitted.

Deserialization — The process of converting a byte stream back into a Java object.

Interface used for Serialization — java.io.Serializable.

Serializable marker interface — An empty interface with no methods; it only marks a class as eligible for serialization.

If a class does not implement Serializable — JVM throws NotSerializableException when attempting to serialize its objects.

ObjectOutputStream & ObjectInputStream — ObjectOutputStream writes objects to a stream; ObjectInputStream reads objects back from the stream.

serialVersionUID — A unique version identifier for a Serializable class used to verify compatibility during deserialization.

Why serialVersionUID is important — It ensures that the sender and receiver of a serialized object have compatible class versions.

How JVM generates serialVersionUID automatically — JVM creates it using class metadata (name, fields, methods, modifiers, etc.) if not explicitly defined.

Default serialization — Automatic serialization where JVM serializes all non-transient, non-static fields.

Can static variables be serialized? — No, static variables belong to the class, not the object, so they are not serialized.

-------------------------------------------------------------------------------------------------------

transient keyword — Used to skip a field from serialization; its value is not saved in the byte stream.

Can final variables be serialized? — Yes, final instance variables are serialized like normal non-transient fields.

Can constructors run during deserialization? — Constructors of serializable classes are not called; only non-serializable superclass constructors execute.

How to make a class partially serializable? — Mark fields as transient or implement custom serialization logic.

If superclass is not serializable — Its default constructor runs during deserialization to initialize inherited fields.

How to prevent serialization of some fields — Use the transient keyword.

Externalizable interface — An interface that gives full control over serialization using writeExternal() and readExternal() methods.

Serializable vs Externalizable — Serializable uses default JVM serialization; Externalizable requires manual serialization logic and more control.

Custom serialization — Defining your own serialization behavior using writeObject() and readObject() methods.

writeObject() and readObject() — Special methods used to customize how objects are written to and read from streams during serialization.

============================================================================================================

How serialization works internally in JVM — JVM converts object state into bytes using reflection, stores class metadata, field values, and object references, then reconstructs them during deserialization.

Object graph in serialization — The complete set of objects reachable from the main object through references that gets serialized together.

Circular references handling — JVM tracks object references and writes handles instead of duplicating objects, preventing infinite loops.

Serialization proxy pattern — A pattern where a separate proxy object is serialized instead of the original class to improve safety and control.

How to secure serialized objects — Validate input, use object filtering, encrypt streams, and avoid deserializing untrusted data.

Serialization vulnerabilities — Security issues where malicious serialized data can execute unintended code during deserialization.

How to avoid deserialization attacks — Use validation, whitelist allowed classes, enable ObjectInputFilter, and avoid native serialization for untrusted sources.

Serialization impact on performance — It is slower and heavier due to reflection, metadata handling, and large byte streams.

When NOT to use Java serialization — For APIs, network communication, long-term storage, or untrusted environments.

How frameworks avoid native serialization — They use formats like JSON, XML, Protocol Buffers, Kryo, or custom binary serializers instead.


============================================================================================================

Changed class structure after serialization — Deserialization works only if class versions are compatible; otherwise it may fail with an exception.

Added new field — will old serialized object work? — Yes, if serialVersionUID matches; the new field gets default value (null, 0, false, etc.).

serialVersionUID mismatch — error — java.io.InvalidClassException.

Serialize Singleton properly — Implement readResolve() to return the same singleton instance during deserialization.

Serialize immutable objects — They can be serialized normally; just ensure fields are final and state is validated during deserialization if needed.

Serialize Lambda expressions — Yes, only if the lambda’s target type implements Serializable; otherwise it fails.

 1. Write code to serialize and deserialize object.

    import java.io.*;

    class Student implements Serializable {
        private static final long serialVersionUID = 1L;

        String name;
        int age;

        Student(String name, int age) {
            this.name = name;
            this.age = age;
        }
    }

    public class Main {
        public static void main(String[] args) throws Exception {

            Student s1 = new Student("John", 22);

            // Serialization
            ObjectOutputStream out =
                    new ObjectOutputStream(new FileOutputStream("student.ser"));
            out.writeObject(s1);
            out.close();

            // Deserialization
            ObjectInputStream in =
                    new ObjectInputStream(new FileInputStream("student.ser"));
            Student s2 = (Student) in.readObject();
            in.close();

            System.out.println(s2.name + " " + s2.age);
        }
    }


 2. Custom serialization using writeObject/readObject.
    import java.io.*;

    class Employee implements Serializable {
        private static final long serialVersionUID = 1L;

        String name;
        transient String password;   // sensitive data

        Employee(String name, String password) {
            this.name = name;
            this.password = password;
        }

        // Custom serialization
        private void writeObject(ObjectOutputStream out) throws IOException {
            out.defaultWriteObject();
            out.writeObject(password + "_encrypted");
        }

        // Custom deserialization
        private void readObject(ObjectInputStream in)
                throws IOException, ClassNotFoundException {
            in.defaultReadObject();
            String val = (String) in.readObject();
            password = val.replace("_encrypted", "");
        }
    }

    public class Main {
        public static void main(String[] args) throws Exception {

            Employee e = new Employee("Mike", "12345");

            ObjectOutputStream out =
                    new ObjectOutputStream(new FileOutputStream("emp.ser"));
            out.writeObject(e);
            out.close();

            ObjectInputStream in =
                    new ObjectInputStream(new FileInputStream("emp.ser"));
            Employee e2 = (Employee) in.readObject();
            in.close();

            System.out.println(e2.name + " " + e2.password);
        }
    }

 3. Serialize object to file and read back.

    import java.io.*;

    class User implements Serializable {
        String username;

        User(String username) {
            this.username = username;
        }
    }

    public class FileExample {
        public static void main(String[] args) throws Exception {

            User user = new User("admin");

            // Write to file
            try (ObjectOutputStream out =
                        new ObjectOutputStream(new FileOutputStream("user.dat"))) {
                out.writeObject(user);
            }

            // Read from file
            try (ObjectInputStream in =
                        new ObjectInputStream(new FileInputStream("user.dat"))) {
                User u = (User) in.readObject();
                System.out.println(u.username);
            }
        }
    }

 4. Serialize object over network socket.

    import java.io.*;
    import java.net.*;

    class Message implements Serializable {
        String text;

        Message(String text) {
            this.text = text;
        }
    }

    public class Server {
        public static void main(String[] args) throws Exception {

            ServerSocket server = new ServerSocket(5000);
            Socket socket = server.accept();

            ObjectInputStream in =
                    new ObjectInputStream(socket.getInputStream());

            Message msg = (Message) in.readObject();
            System.out.println("Received: " + msg.text);

            in.close();
            socket.close();
            server.close();
        }
    }

    import java.io.*;
    import java.net.*;

    public class Client {
        public static void main(String[] args) throws Exception {

            Socket socket = new Socket("localhost", 5000);

            ObjectOutputStream out =
                    new ObjectOutputStream(socket.getOutputStream());

            out.writeObject(new Message("Hello Server"));

            out.close();
            socket.close();
        }
    }
