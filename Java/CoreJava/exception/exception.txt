🔹 Tricky / Trap Questions
⚡ Can we catch multiple exceptions in one catch?
👉 Yes (Java 7 multi-catch)

⚡ Can we have finally without try?
👉 No

⚡ Does finally always execute?
👉 Mostly yes, except JVM crash / System.exit()

⚡ Can constructor throw exception?
👉 Yes

⚡ Can static block throw exception?
👉 Yes (wrapped in ExceptionInInitializerError)
